# Review Agents
Навык ручного вызова, запускать только прямым вызовом `/review-agents`.

## Пошаговый алгоритм работы

### Правила алгоритма
- **ТРЕБУЕТСЯ** работать строго в полном соответствии с алгоритмом.
- **ЗАПРЕЩЕНО** объединять шаги и выполнять работу алгоритма на опережение.

### Шаг 1. Входные данные
- Определи абсолютный путь к переданному локальному файлу или директории.
- ⏸️ Если путь отсутствует или недоступен, уточни его у пользователя.
- Определи абсолютный путь к `rules.md` рядом с этим `SKILL.md`.

### Шаг 2. Параллельное ревью
- ⚠️ (agent) Запусти ровно двух встроенных агентов типа `general-purpose` в фоне.
- Каждому передай один и тот же абсолютный путь к коду, общий промпт и только его задание.

#### Общий промпт для обоих агентов
> Проведи ревью указанного файла или директории. Работай в режиме чтения. Верни результат оркестратору текстом.
>
> Собирай только подтверждённые нарушения с привязкой к коду. Останови поиск сразу, как только найдёшь ТРИ нарушения, и немедленно верни список. Если проверка закончилась раньше, верни то, что нашёл, включая пустой список.
>
> Для каждого нарушения укажи `файл:строка`, основание, суть и конкретное исправление. Заверши ответ маркером `FINISH`. Если проверка прервалась из-за ошибки, верни уже подтверждённые нарушения, причину и маркер `FAIL`.

#### Задание первому агенту
Передай абсолютный путь к `rules.md` вместе с этим заданием.

> Прочитай переданный файл с правилами. Проверь код только по его разделам. Для каждого нарушения процитируй конкретное требование и укажи фрагмент кода, к которому оно относится.

#### Задание второму агенту
> Найди скрытые ошибки на основе своего инженерного опыта. Проверь граничные значения, обработку отказов и порядок асинхронных операций там, где это применимо. Файл с правилами в этой проверке не используй.

### Шаг 3. Отчёт в чат
- Дождись результата обоих агентов. Если один завершился с ошибкой, дождись второго и сообщи, какая проверка осталась неполной.
- Выведи в чат единый нумерованный список всех возвращённых нарушений с указанием проверки, места, основания, сути и исправления. Сохрани сценарий ошибки, если агент его привёл.
- Если оба вернули `FINISH` с пустыми списками, сообщи, что нарушений не найдено.
